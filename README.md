# Device Tree for Realme C15 Qualcomm

The Realme C15 Qualcomm are mid-range smartphones from Realme. These are announced and released in August 2019, November 2019,January 2020.

## Device specifications

| Feature                 | Specification                                                   |
| :---------------------- | :---------------------------------------------------------------|
| Chipset                 | Qualcomm SM4250 Snapdragon 460 (11 nm)                          |
| CPU                     | Octa-core (4x1.8 GHz Kryo 260 Gold & 4x1.8 GHz Kryo 260 Silver) |
| GPU                     | Adreno 610                                                      |
| Memory                  | 4 GB                                                          |
| Shipped Android Version | 10.0                                                             |
| Storage                 | 64 GB                                                    |
| SIM                     | Dual SIM (Nano-SIM, dual stand-by)                              |
| MicroSD                 | Dedicated Slot                                                  |
| Battery                 | 6000 mAh Li-Po (non-removable)                                  |
